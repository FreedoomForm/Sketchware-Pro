## Audit interpretation

The Creator Runtime transaction API currently has seven project-level mutation types: SCREEN_CREATE, WIDGET_ADD, WIDGET_SET_PROPERTY, ENTRY_CONTROL_UPDATE, STATE_SET, EVENT_ATTACH, and REVISION_RESTORE. The legacy artifact importer separately converts many Sketchware block opcodes into service calls. Therefore, an original editor surface can open and save legacy data while live execution still depends on conversion coverage and service registration.

The importer emits service IDs including ads_interstitial, animator, bitmap, bluetooth, calendar, camera, date_picker, dialog, drawer, file, file_picker, firebase, firebase_auth, firebase_storage, gyroscope, http, intent, local_storage, location, map, media, speech_to_text, text_to_speech, time_picker, timer, ui, vibrator, and widget. CreatorRuntimeServices registers corresponding concrete host services plus notification, rewarded ads, Firebase messaging, phone/google auth, and fragment adapter. The remaining implementation gate is a parity regression test asserting every imported service ID is registered and every unsupported/deferred block is surfaced through CreatorCompatibilityReport and legacy.deferredEvents rather than silently disappearing.
